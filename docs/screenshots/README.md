# Nextcloud App Store Screenshots

This directory contains the screenshots displayed on the official Nextcloud App Store page for **ND Downloader**.

## Included Screenshots

1. **`dashboard.png`**  
   - **View:** ND Downloader main interface showing active/completed downloads, speed indicators, and sidebar filters.  
   - **Referenced in:** `appinfo/info.xml`  
   - **Recommended resolution:** 1920x1080 or 1280x720 (PNG)

2. **`admin-settings.png`**  
   - **View:** Nextcloud Administration Settings > Additional Settings showing the ND Downloader server connection configuration and test connection status.  
   - **Referenced in:** `appinfo/info.xml`  
   - **Recommended resolution:** 1920x1080 or 1280x720 (PNG)

## How to Refresh Before Publishing

To refresh or customize these screenshots:
1. Open Nextcloud in a browser with a clean 1080p viewport (zoom 100%).
2. Capture the ND Downloader main dashboard with 1–2 sample download tasks active/complete.
3. Save as PNG to `docs/screenshots/dashboard.png`.
4. Capture the Admin Settings page and save to `docs/screenshots/admin-settings.png`.
5. Ensure the filenames match the `<screenshot>` URLs declared in `appinfo/info.xml`.
